# พรอมต์สำหรับเซลส์: สร้างเว็บ B2B + แชทบอท AI เสียง/3D (วางใน AI ครั้งเดียว)
สร้างระบบเว็บสั่งซื้อ B2B พร้อมแชทบอท AI ฟัง-พูด-อ้างอิงเอกสารและหน้าเว็บ 3D แบบครบวงจรสำหรับร้านของฉัน จากข้อมูลที่เตรียมไว้ดังนี้:
1. [ข้อมูลร้านและช่องทางติดต่อ]: <ใส่ชื่อบริษัท, เบอร์โทรเซลส์, LINE, เลขบัญชีรับโอน, เวลาทำการ/วันหยุดประจำปี, ภาษาที่รองรับ (TH/EN)>
2. [ตารางสินค้าและราคาตั้งต้น]: <แนบไฟล์ CSV/Excel หรือระบุรายการสินค้า: รหัส, รุ่น, ขนาด, สี, ราคาต่อหน่วย, จำนวนสั่งขั้นต่ำ (MOQ), รูปสินค้า>
3. [กฎธุรกิจและการคิดเงิน]: <ระบุขั้นส่วนลดตามจำนวน/ช่วงวันที่, ค่าพิมพ์โลโก้+ขั้นต่ำ, เกณฑ์ค่าขนส่งตามระยะทาง/จำนวนต่อเที่ยวรถ, เงื่อนไขเครดิต, กฎขอตัวอย่างและเคลม>
4. [เอกสารความรู้ของร้าน (PDF)]: <วางไฟล์ PDF คู่มือสเปกสินค้า/โลโก้/QC/การใช้งาน/ขนส่ง/นโยบาย/FAQ ไว้ใน docs/pdf/ (ห้ามใส่ราคาสินค้าใน PDF)>
5. [มาสคอตและเสียงต้นฉบับ]: <ระบุชื่อมาสคอต, รูปลักษณ์ 3D, คำลงท้าย และวางไฟล์เสียงต้นฉบับ 5–15 วินาทีใน voices/ สำหรับโคลนเสียงอ่าน TTS>
6. [งบประมาณและบัญชี]: <ระบุเพดานค่าเช่า GPU บน Vast.ai ต่อชม. (เริ่มต้น ≤ $2.20/ชม.) และล็อกอินบัญชี AI agent / Docker ในเครื่องให้พร้อม>
---
คำสั่งให้ทีม AI ดำเนินการอัตโนมัติจนจบ (เป้าหมาย: เซลส์ลงมือ ≤ 1 ชม. · เวลารวมทั้งระบบ ≤ 3 ชม. · ระหว่างทางไม่ต้องให้คนช่วย):
- แตกงานเป็น DAG แล้วสร้างเว็บแอปใหม่ (Next.js 14 + PostgreSQL/pgvector + RabbitMQ) แยกสิทธิ์ข้อมูลลูกค้าแต่ละบริษัท (B2B) อย่างเคร่งครัด
- สร้างระบบสั่งซื้อ, คำนวณราคา/ส่วนลด/ค่าส่ง/VAT จากโมดูลกฎกลางที่เดียว, แจ้งเตือนสั่งเพิ่มถูกกว่า (upsell), ออกใบเสนอราคา (QT) พิมพ์และแปลงเป็นออเดอร์ได้ พร้อมระบบหลังร้านและแจ้งเตือนสด
- สร้างฉากหน้าแรกและโมเดลสินค้า 3D หมุนดูได้ (Three.js + โหมดสำรอง 2D เมื่อไม่มี WebGL) และมาสคอต 3D 4 สถานะที่ขยับปากตามเสียงพูดจริง
- สร้างแชทบอทที่ตอบจาก DB + กฎคำนวณราคา + ค้นเอกสาร PDF ด้วย Hybrid RAG (pgvector + pg_trgm + RRF + Reranker) พร้อมป้ายอ้างอิงคลิกเปิดหน้า PDF ได้
- เชื่อมต่อระบบถามด้วยเสียงไมโครโฟน (Whisper STT) และอ่านคำตอบออกเสียงทีละประโยคแบบขนานกับ LLM (VoxCPM2 TTS) ผ่านคิว RabbitMQ แยกตาม GPU
- สร้างชุดคำถามประเมิน RAG จาก PDF ทุกเล่ม (≥ 100 ข้อ/เล่ม ตรวจความถูกต้องด้วยโมเดลอิสระ + Canary) และสร้างหน้าแดชบอร์ด `/admin/eval` กับ `/admin/load`
- รันทดสอบอัตโนมัติ Playwright ครบทุกฟีเจอร์ (เว็บ, แชท, RAG, คิว, เสียง, 3D, แดชบอร์ด) พร้อมอัดวิดีโอ/GIF และยิง Load Test วัดจำนวนผู้ใช้สูงสุดที่รองรับได้จริง (p95 ≤ 12 วิ, error ≤ 1%)
- เมื่อฉันอนุมัติงบ GPU ให้เช่า Vast.ai 3 ใบ (LLM, STT, TTS+Rerank) ทดสอบจริงและทดสอบขยายระบบ (×2, ×4) สรุปรายงานทั้งหมด แล้วสั่งทำลาย (destroy) GPU ทันทีเมื่องานจบ
